任务数据统计字段说明

筛选区字段

  • 日期范围：默认收起，仅展示开始日期、结束日期和日历图标。
  • 打开日历：点击日期范围输入框后弹出双月日历面板。
  • 选择日期：第一次点击设置开始日期，第二次点击设置结束日期；若第二次日期早于开始日期，则自动交换起止日期。
  • 关闭日历：点击确定或点击控件外部关闭；点击清空后重置起止日期。
  • 任务类型：筛选 Regular、Guild、Events 或全部。

核心指标定义

  • 访问用户 UV：统计周期内进入任务中心页面的去重用户数。
  • 完成用户 UV：统计周期内至少完成 1 个任务的去重用户数。
  • 完成次数：统计周期内任务完成事件总数，同一用户完成多个任务分别计数。
  • 已领取积分：统计周期内用户领取成功并完成入账的积分总量。
  • 装扮发放数：虚拟装扮奖励发放成功的总次数。

任务类型完成表现

  • 任务类型：展示 Regular、Guild、Events 三类任务的汇总结果。
  • 完成次数：该类型任务在统计周期内产生的完成事件总数。
  • 完成用户：该类型下至少完成 1 个任务的去重用户数。
  • 已领取积分：该类型下所有积分奖励领取成功并入账的总积分。
  • 装扮发放数：该类型下所有虚拟装扮奖励发放成功的数量。
  • 完成占比：该类型完成次数 / 全部类型完成次数，用于顶部百分比和进度条。

任务配置字段说明

查询与新建

  • 任务类型：筛选 Regular、Guild、Events。
  • 任务状态：筛选草稿、已上线、已下线等配置状态。
  • 奖励类型：筛选积分任务或物料装扮任务。
  • 新建任务：打开任务配置弹窗。

列表字段

  • 任务 ID：后台生成的唯一标识。
  • 任务标题：前端任务卡展示标题。
  • 展示 Tab / 分组：决定任务展示在哪个 Tab 和哪个分组下。
  • 奖励：展示积分数量或虚拟装扮名称。
  • 排序：同分组内按排序值从小到大展示。
  • 编辑：点击后打开同一个任务配置弹窗。

新建 / 编辑弹窗字段

入口与展示限制

  • 展示 Tab：Regular 可选 Newbie Tasks / Daily Tasks；Guild 固定 Tasks for guild；Events 固定 Event Tasks。
  • Guild 适用对象：选择 Guild 时展示，可选“仅主播”或“公会内所有人”。
  • Events：不展示任务条件配置，只在任务说明下方展示“活动积分”输入框。

基础信息

  • 任务标题：App 任务卡主标题，建议使用简短英文。
  • 图标资源：通过上传组件选择 PNG / JPG / WebP，上传成功后由后端返回资源 ID 或 URL。
  • 排序值：同一分组内按数值从小到大展示。
  • 任务说明：点击 App 任务卡标题后的问号时展示，说明任务达成规则。

任务行为条件

  • Regular：支持充值、上麦、送礼、收礼、商城消费、购买 VIP、玩游戏。
  • Guild：支持 Regular 的全部行为，并额外支持主播任务。
  • 充值：首充 / 非首充；目标值填写美元金额。
  • 上麦：目标值填写分钟，按有效上麦时长判断。
  • 送礼 / 收礼：可按礼物个数或金币价值判断；指定礼物时填写礼物 ID。
  • 商城 / VIP / 游戏：商城和 VIP 无需目标值；游戏目标值填写金币下注金额。

主播任务

  • 新手福利：成为主播后 7 天内生效，一次配置 1 小时、2 小时、3 小时三个积分档位。
  • App 展示：展示为一张“新手福利”任务卡，进度为累计有效上麦时长，目标展示到 3 小时。
  • 里程碑发放：达到 1h / 2h / 3h 时分别发放对应积分；已发放档位不重复发放。
  • 非新人主播：引用主播档位系统返回的当天时长要求和档位奖励，不在任务中心维护 A-L 明细。
  • 奖励方式：选择“引用档位奖励”时隐藏固定积分输入；选择“固定积分”时才填写固定积分。

奖励与动作

  • 积分奖励：仅展示奖励值输入框。
  • 物料装扮：仅展示物料 ID 输入框。
  • 行动按钮：按钮文案由前端按任务状态和行为类型生成。

用户与奖励记录字段说明

查询条件

  • 用户 ID：查询指定用户的任务进度和奖励记录。
  • 任务 ID：查询指定任务在用户侧的完成和发放情况。
  • 发放状态：仅支持成功、失败；进行中的任务不进入奖励发放记录。
  • 时间范围：查询任务完成并触发奖励发放的时间区间。

用户任务与奖励记录字段

  • 记录 ID：奖励发放记录唯一标识。
  • 完成进度：展示任务完成时的最终进度，如 10/10。
  • 完成时间：任务达成并触发奖励发放的服务端时间。
  • 奖励类型：积分或物料装扮。
  • 发放状态：仅展示成功或失败。
  • 失败原因：发放失败时展示服务端返回原因；成功时显示 -。
  • 操作：失败记录展示重发按钮；成功记录仅支持查看详情。
